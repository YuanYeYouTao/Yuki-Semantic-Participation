# 连续自主参与模型

2026-09-23 开发分支实现。本文对应 `dynamics.py`、`Controller.opportunity_scores()` 和
`Controller.intrinsic_opportunity()`；合并与上线状态以 Host 固定的依赖提交和部署记录为准。
完整设计背景见 Yuki Host 的 `docs/architecture/autonomous-participation-model.md`。

## 决策边界

明确邀请或经有效语义观测确认的直接续答仍走请求路径，立即产生 proposal。对
`open_group`、`recall`、`contact` 和无来源 `intrinsic`，控制器将“不启动 SELF 回合”
的价值定为 0，计算各候选的净机会值，选择正值最大的一个。0 是资源/打断成本后的
不行动基准，不是随时间积累的第二道门槛。已删除旧 `rate()`、`rates()`、指数随机阈值、
hazard 与 900/3600/1200 秒固定静默条件。

执行资格仍由合法来源版本、语义支持、停止边界、群授权、唯一 owner 与 Host CAS 等
事实约束决定；数学分数不授予权限。独立库只提出机会，Yuki Main Agent 决定工具、
明确发送或 `NO_REPLY`。

## 状态与方程

O/H/Y/E/C 及注意 `x` 保留现有事件与 Jev 更新，随时间衰减。活动 `q`、确认发言
`p`、实际计算 `f` 保留原有饱和跃迁与泄漏；SELF `engage` 只更新参与倾向 `d`，
以 1800 秒时标回中性。自由字符串 `mood` 不推断心理状态，图扩散仍取 `κ=0`。

```text
D(d) = 0.15 + 0.85(d+1)/2
R = N_Y/(N_Y+N_H)；分母为 0 时 R=0
C = 0.08p + 0.04f + 0.02q
    + 0.1 min(1,N_Y+N_H)[R-0.35]₊ + 0.025
social_i = D(d)x_i/(1+0.15h_i) + 0.35b_H+0.25b_E-0.15b_Y-0.70b_C
opening_i = (1-exp(-gap_i/4))(0.1+0.9floor_i)
L_i = 1-(1-ℓ)(1-H_i)
U_i = S_i opening_i L_i[social_i]₊ - C - c_ind,i
```

`h_i` 仅由同类型、同讨论与对象的真实已接纳回合增加，随后按会话 600 秒、
回忆/联系 21600 秒衰减。`H_i` 是候选中真实本群真人来源的注意，纯记忆取 0。
`ℓ` 使用已提交真人事件与现行活动跃迁权重 0.1，但按 3600 秒衰减，比 `q` 慢。
`S_i` 仍是有效语义支持，来源撤回、有效期与范围规则保持不变。`c_ind,i` 对
回忆/联系为 0.05；会话加入为 0。

无来源群内参与使用同一慢速群情境，同时让自身恢复与群沉寂产生相反作用：

```text
g = 1-exp(-(t-t_ref)/1800)
U_self = 0.4 D(d) g ℓ(1-q)(1-p)
         -0.04f -0.1 min(1,N_Y+N_H)[R-0.35]₊ -0.025-0.05-0.05n
```

`t_ref` 取初始化、上次**已接纳**的无来源 SELF 回合及上次确认发言的较晚者。
拒绝和 busy 不推进它。`n` 只由无来源回合的真实 `NO_REPLY` 更新，以 0.45 的饱和
跃迁增加、1800 秒衰减；它不是情绪或社交评价。trace 与熟悉度写入控制器快照，
十分钟来源窗口裁剪及恢复后仍可连续推进。旧快照的 hazard/threshold/提议时间字段
只做兼容读取并移除，不把旧提议误认为已接纳回合。

当没有新的本群真人输入时，`ℓ,H_i→0`；社会收益有界，单次调用成本 `0.025>0`，
故所有非请求式公开群聊候选的净值最终为负。中期恢复曲线仍可能为正。这里没有
“沉默超过多少小时就禁止发言”的时间判断；合法真人直接请求仍可回应。

## 验证与界限

单元回归覆盖：无来源回合接受后不热循环；极久沉寂和纯记忆不会恢复公开提议；
确认发送重置恢复；`NO_REPLY`、熟悉度和慢群情境跨裁剪/重启保留；来源失效、
明确邀请和现有安全边界继续有效。

`scripts/replay_autonomous_evolution.py` 使用 `fixtures/group-chat-workload-v2-full.json.gz`
的两条 30 天合成轨迹，控制器跨日连续，记录型执行器对每次 proposal 返回
`NO_REPLY`。报告写入 `docs/evidence/autonomous-evolution-v1-replay.json`。夹具只按
用户服务器的只读聚合校准活动规模、间隔与消息长度；正文、语义标签与 SELF 效果
均为合成，不能代表真实 Jev、Main Agent 发言率或群友感受。具体报告与源码哈希
须在最后一次代码修改后重新生成。

本次固定回放覆盖 15,952 条合成真人消息和 41 个超过 6 小时的真人空档，产生
2,679 次 proposal，其中 118 次为无来源机会；距上条真人消息超过 6 小时的
proposal 为 0，最大间隔约 32 分钟。所有回合均由记录器反馈 `NO_REPLY`，实际发送
为 0。另有 5 次 proposal 发生在尚未评分的同讨论结束/停止输入之后；Yuki Host
接纳层须继续核验并阻断，这项风险不能由连续机会值代替。
