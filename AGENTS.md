# Development contract

Implement the V6 semantic participation boundary. This library proposes opportunities;
it never sends messages, creates work, steers agents or imports Yuki internals.
Events and permissions come from the host. Unknown, missing, predicted and ended are distinct.
Never fabricate semantic observations or describe fixtures as real provider validation.
No daily action quotas. No provider calls inside database transactions.
Document unfinished integration and experimental parameters. Keep tests focused on invariants.
Do not publish real conversations, deployment files, credentials or local runtime databases.
